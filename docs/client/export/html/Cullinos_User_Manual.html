1. First-time owner setup

1

Log in to Admin

Open admin.cullinos.com with the owner email and password from onboarding.

2

Complete Setup wizard

Choose business type (e.g. Restaurant), enter GSTIN if you have one, and finish the guided steps.

3

Build your menu

Admin → Menu: create categories, then items with prices. Toggle availability when an item sells out.

4

Add tables

Admin → Tables: create floor tables (e.g. T1, T2) so Waiter can take dine-in orders.

5

Invite staff

Admin → Staff: add a Waiter and a Cashier, assign your outlet, share passwords securely.

2. Taking orders — Waiter (dine-in)

1

Open Waiter

waiter.cullinos.com → log in → select outlet → see the table grid.

2

Open a table

Tap a table → add menu items → confirm. Note the order number.

3

Optional: guest QR

Use Show QR to customers so guests order on their phones into the same table ticket. End the session when the table clears.

4

Kitchen sees it

KOTs appear on KDS (kds.cullinos.com) within seconds.

3. Taking orders — POS (counter / takeaway)

1

Open POS

pos.cullinos.com as Cashier — or Admin → Portal POS (/pos) if you have POS access.

2

Build the cart

Tap items, set order type (e.g. takeaway), check subtotal.

3

Hold if needed

Hold an order to free the screen; resume later from the held panel.

4

Checkout

Confirm the quick order. It shows in Admin → Orders and on KDS.

4. Online & QR guest ordering

  1. Share https://order.cullinos.com/your-org/your-outlet or the waiter QR link.
  2. Guest browses menu → cart → checkout with name & phone.
  3. Prefer Pay later unless Razorpay is configured for Pay now.
  4. Verify the order in Admin → Orders.

Customer login is optional — guests can always checkout without an account.

5. Kitchen & Order Display

Kitchen Display

Open kds.cullinos.com (or Admin → Kitchen Display launcher). Tickets update live as orders arrive. Mark items as you cook.

Order Display

Admin → Order Display (/cds). Copy the public board URL to a tablet/TV so guests see Preparing → Ready.

7. Multi-outlet (Enterprise)

  1. Open manage.cullinos.com with the owner login.
  2. Review network KPIs on Overview.
  3. Compare outlets or create stock transfers when you have 2+ outlets.

8. Tips & good habits

  • Create staff accounts per person — don’t share the owner login on the floor.
  • Keep menu availability updated so guests never order sold-out items.
  • End QR table sessions when guests leave so old links stop working.
  • Use Incognito when testing the customer storefront as a guest.
  • Never put real passwords in shared spreadsheets or chat.
