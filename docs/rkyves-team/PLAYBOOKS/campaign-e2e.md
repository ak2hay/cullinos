# Playbook: Growth Campaign

**Group:** Growth Campaign  
**Skill:** `/rkyves-orchestrate-e2e`

## Stages

| Stage | Owner | Exit criteria |
|-------|-------|---------------|
| 1. Brief | Marketing | Audience, offer, channel, success metric |
| 2. SEO | SEO | Keywords, page targets, technical notes for apps/web |
| 3. UX | UI/UX | Flow/wire outline; brand alignment |
| 4. Build | Dev Frontend | PR to develop if code/content in repo |
| 5. QA light | QA (optional) | Links, mobile layout, CTAs |
| 6. Human gate | Human | Approve publish / paid spend / social send |

## Marketing brief fields

- Campaign name / dates
- Audience (owners, chains, region)
- Message (one sentence)
- Channels (web, email, WhatsApp draft, social)
- CTA
- Compliance: no false claims; cite PRODUCT.md

## Hard stops

- Drafts only until human approval
- No customer spam; no invented pricing
